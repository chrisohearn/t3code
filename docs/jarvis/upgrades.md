Provider fallback is automatic in T3: an account failure (usage or rate limit,
sign-in or billing) that the Codex or Claude adapter proves happened before any
assistant output, tool call or file change re-sends the message once on the
fallback model, with a notice, and the thread stays on that model. On .9 a Revotech
usage limit produced one failover run on Claude Opus 5.5. Jarvis's manual relaunch
rule is retired; relaunching as well would run the message twice. Restart work
verifies existing recovery; it adds no draining code. Adaptive scheduler backoff
and cost guardrails were dropped.
