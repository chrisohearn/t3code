# The ledger owns shared work state

Accepted 2026-11-12.

## Decision

The T3 fork's work ledger tracks all shared work. The Slack Bugs List mirrors the ledger and has one writer, the F01 thread.

## Alternatives

Keep the hand-maintained registry, or allow each worker to update the Slack list independently.

## Why

A shared record and a single mirror writer prevent competing accounts of the same work. The ledger choice dates to November 11; the F01 writer rule dates to November 12.
