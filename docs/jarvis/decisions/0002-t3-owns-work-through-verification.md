# T3 owns accepted work through verification

Accepted 2026-11-11.

## Decision

Jarvis handles non-repo work and tries machine work first. T3 receives repo work or work blocked by two failed tries or missing access. Once T3 accepts it, T3 carries it through to a verified result. Jarvis handles the people-side wrap-up.

## Alternatives

Send all work to T3, or let T3 hand cheap work back to Jarvis.

## Why

The split uses Jarvis for its existing work while giving each T3 assignment a clear finish line. Reverse delegation of cheap work was dropped.
